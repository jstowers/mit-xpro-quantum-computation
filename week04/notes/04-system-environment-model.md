## What is an Error?

What are all the possible ways that an input density matrix, ${\rho_{in}}$ can evolve to an output density matrix, ${\rho_{out}}$?

A map called $E$ will capture:

    1. Any physical process happening to the input state

    2. Includes any unitary evolution and any non-unitary evolution

The mapping of an input density matrix to an output density matrix is an important concept for QEC.
